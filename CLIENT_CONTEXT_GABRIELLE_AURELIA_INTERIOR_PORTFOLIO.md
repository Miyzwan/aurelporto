# 21. WEBSITE VISUAL DIRECTION

The website can take inspiration from highly interactive editorial portfolios such as `itsjay.us`, but it must not become a clone.

### Recommended principles

- editorial layout
- oversized typography
- restrained color palette
- large interior renders
- architectural grid
- strong whitespace
- project-first presentation
- controlled motion
- material-led storytelling
- floor-plan-to-space transitions
- project-specific interaction

### Avoid

- excessive WebGL
- random cursor gimmicks
- gaming-style UI
- neon gradients
- glassmorphism-heavy interfaces
- excessive parallax that distorts room perspective
- animation that makes interior imagery difficult to inspect

The work must remain the primary visual subject.
